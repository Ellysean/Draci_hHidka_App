# Zdroje pravidel pro appku

Sem patří PDF (a případně xlsx s tabulkami) k jednotlivým povoláním, ze kterých se budou dělat fáze 7b–7e.
Každé povolání má svou podsložku. Stačí soubor nakopírovat a v chatu napsat, že je tam – appka si ho odtud načte.

| Složka | Fáze | Co sem dát |
|---|---|---|
| `valecnik/` | 7b | H08 Válečník, PPP01 Válečník (už je v projektu), případné tabulky triků a Cest |
| `hranicar/` | 7c | H09 Hraničář, PPP02 Hraničář, **tabulka zvířecích přátel (H09 s. 14)** a duševní síly pro úrovně 7–24 |
| `kouzelnik/` | 7c | H11 Kouzelník, PPP04 Kouzelník |
| `klerik/` | 7d | H13 Klerik, PPP06 Klerik, **seznamy proseb nauk a atributy poslů** |
| `zlodej/` | 7e | H12 Zloděj, PPP05 Zloděj |
| `alchymista/` | 7a+ | PPP03 Alchymista (celé PDF je už nahrané v chatu 27. 9. 2026) |
| `spolecne/` | – | cokoliv společného (Bestiář, Cizí postavy, opravy tabulek) |

Názvy souborů klidně ponech původní. Pokud je PDF naskenované (bez textové vrstvy), přidej i xlsx s tabulkami.
